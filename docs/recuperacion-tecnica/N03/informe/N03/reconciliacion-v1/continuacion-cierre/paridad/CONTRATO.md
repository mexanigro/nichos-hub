# Paridad: caracterización de cinco excepciones existentes

Alcance congelado: GET /api/services, POST /api/availability, POST /api/bookings/validate, GET /api/daily-digest y GET * SPA. Sin producto, nueva oferta, otro consumidor, instalación ni efecto externo. Fuentes físicas anteriores a ejecución en preimagenes y PREIMAGENES.json. Node/TypeScript/Express instalados; Docker imagen existente, network none, entorno vacío, filesystem readonly salvo salida/tmp.

P0: fuente y contrato congelados. P1: ejecutar registros AST literales en Express real y peticiones HTTP loopback; DB/token/email/log interceptados. P2: retirar cada registro y desarmar cron en copias en memoria; conservar resultados, comprobar sensibilidad y límites. DONE: informe de excepciones acreditadas y no acreditadas.

Expectativas anteriores a ejecución: services produce proyección id/name/duration/price, respeta errores 404/502/503/500, tenant en destino; availability rechaza falta/formato y responde echo para formato válido, sin consultar slots; validate rechaza campos/duración inválidos y admite payload válido sin persistir; digest exige secreto/token/proyecto antes de lecturas, consulta tenant y fecha, distingue queued/failed/sent ante transporte simulado, propietario ausente no envía; SPA devuelve index ante deep link y API específica prevalece. Vercel mantiene rewrite API anterior a catchall y cron declarado. No reinterpretar esos éxitos como reserva, disponibilidad, entrega o scheduler efectivos.

GREEN: expectativas, registros y ausencia de efectos prohibidos satisfechas; mutantes RED por pérdida de registro/resultado o ejecución digest sin secreto correcto. RED: incumplimiento. Es caracterización de contratos vigentes, no reparación: no se exige inventar defecto basal. Un error del instrumento no es RED semántico, se conserva separado.

Límites: llamadas app.get/post y callbacks reales extraídos por AST, no startup completo. Middleware global origen/auth/cuota no ejecutado ni certificado. El guard interno cron sí se ejecuta. Validadores reales; upstream Firebase/Resend/logs simulados. SPA usa archivo index sintético y static real; rewrite Vercel se contrasta como configuración, no plataforma alojada. CENSO adjudica helpers a monitor; bookingCheck actual consume services/availability y se conserva como evidencia, no se ejecuta su escritura métrica. La ausencia de caller observado para validate no es ausencia universal. No decidir política comercial digest.
